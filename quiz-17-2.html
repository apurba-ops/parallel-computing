Under output data decomposition, what does the Owner Computes Rule require when process \(P_k\) is assigned output element \(C_{i,j}\)?
  • (A) \(P_k\) must own all input matrices \(A\) and \(B\) entirely in local DRAM.
  • (B) \(P_k\) performs all computations that contribute to \(C_{i,j}\), fetching non-local entries of \(A\) and \(B\) as required.
  • (C) \(P_k\) delegates the computation to the master thread 0.
  • (D) \(P_k\) cannot perform floating-point operations.
Answer: (B) Process Computes Its Assigned Output Data
• Why (B) is True: The Owner Computes Rule mandates that whichever process is designated as the "owner" of an output data location must execute all instructions that write to that location. In output decomposition, \(P_k\) owns \(C_{i,j}\) and therefore computes its dot products, retrieving any necessary rows of \(A\) or columns of \(B\) across the network.
• Why others are false: Replicating all inputs locally is often memory-prohibitive; master delegation defeats parallel scaling; processors compute their assigned floating-point instructions locally.
2
In exploratory search, how can a 4-processor parallel system achieve an anomalous speedup of \(S_p = 2001\) over a serial depth-first search?
  • (A) Hardware clock speeds quadruple during parallel search.
  • (B) Serial DFS searches two unpromising subtrees of size \(m=1000\) before reaching the solution, while parallel processor 3 hits the solution at step 1 and aborts all tasks.
  • (C) Cache misses become negative numbers.
  • (D) Superlinear speedup is mathematically impossible in physical reality.
Answer: (B) Search Ordering Serendipity
• Why (B) is True: If Subtree 1 and Subtree 2 have size \(m=1000\) and contain no goal state, serial DFS executes \(2m + 1 = 2001\) steps before reaching the solution in Subtree 3. A 4-core parallel search assigns one core to Subtree 3, which discovers the solution at step 1 (\(T_p = 1\)) and broadcasts a termination signal, yielding \(S_p = 2001 / 1 = 2001 \gg 4\).
• Why others are false: Processor clock rates remain fixed; cache misses cannot be negative; anomalous superlinear speedup in exploratory search is well documented because the total work performed in parallel is drastically smaller than serial work (\(W_p \ll W_s\)).
3
When mining itemsets in a transaction database, why does input data decomposition require communication while output data decomposition does not?
  • (A) Input decomposition splits transactions across nodes, generating partial frequency counts that must be summed via parallel reduction.
  • (B) Output decomposition uses optical interconnects.
  • (C) Transactions cannot be stored in RAM.
  • (D) Output decomposition modifies the input transactions.
Answer: (A) Partial Count Reduction Across Nodes
• Why (A) is True: In input data decomposition, each node only accesses a subset of transactions. Therefore, each node computes a partial occurrence count for each candidate itemset. These partial counts must be communicated and summed globally via reduction. In output decomposition, candidate itemsets are partitioned among nodes while the entire database is replicated, so each node independently computes exact global counts.
• Why others are false: Algorithmic dependencies are independent of optical interconnects; transaction sets fit in memory/disk; output decomposition is strictly read-only.
4
Why does Matrix Multiplication allow multiple distinct decompositions (e.g., Decomposition I vs. Decomposition II) for the identical output block partition?
  • (A) Matrix multiplication is non-associative.
  • (B) Addition of partial products is commutative and associative (\(A + B = B + A\)), permitting reordering of accumulation tasks.
  • (C) Floating point numbers never overflow.
  • (D) Only Decomposition I is mathematically valid.
Answer: (B) Algebraic Commutativity & Associativity of Addition
• Why (B) is True: Evaluating \(C_{1,2} = A_{1,1}B_{1,2} + A_{1,2}B_{2,2}\) involves summing partial products. Because algebraic addition is associative and commutative, \((A_{1,1}B_{1,2}) + (A_{1,2}B_{2,2})\) can be accumulated in different orders or assigned to different stages. This permits multiple distinct task dependency graphs with different memory footprints and communication characteristics for the exact same output partitioning.
• Why others are false: Matrix multiplication is associative; overflow is irrelevant to decomposition definition; both decompositions are mathematically valid.
