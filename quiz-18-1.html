For an \(n \times n\) dense matrix algorithm executed on \(p\) processors, why is 2-D checkerboard block distribution asymptotically superior to 1-D block distribution?
  • (A) 2-D distribution reduces inter-process boundary communication perimeter by an asymptotic factor of \(\sqrt{p}\).
  • (B) 2-D distribution eliminates the need for floating-point arithmetic.
  • (C) 1-D distribution requires an infinite number of processors.
  • (D) 2-D distribution can only be implemented on GPU architectures.
Answer: (A) \(\sqrt{p}\) Asymptotic Communication Reduction
• Why (A) is True: In 1-D block partitioning, each process owns a strip of size \((n/p) \times n\). The boundary perimeter per process is \(2n\), yielding communication volume \(O(n)\). In 2-D checkerboard partitioning, each process owns a square block of size \((n/\sqrt{p}) \times (n/\sqrt{p})\) with boundary perimeter \(4(n/\sqrt{p})\), yielding communication volume \(O(n/\sqrt{p})\). This represents an asymptotic reduction by a factor of \(\sqrt{p}\) in the surface-to-volume ratio! Furthermore, 2-D distribution allows scaling up to \(p \le n^2\) processors, whereas 1-D is strictly capped at \(p \le n\).
• Why others are false: 2-D partitioning does not alter arithmetic; 1-D is practical on CPUs but suffers from higher communication volume and limited concurrency ($p \le n$).
2
In Gaussian elimination of dense matrices, why does 1-D cyclic distribution dramatically outperform 1-D block distribution?
  • (A) It converts the linear algebraic solver into a binary reduction tree.
  • (B) It interleaves rows round-robin across processes, ensuring that as upper rows are eliminated, remaining computational work stays uniformly balanced across all processors.
  • (C) It eliminates inter-process communication entirely.
  • (D) It restricts the matrix to diagonal entries only.
Answer: (B) Even Load Balance Across Triangular Elimination
• Why (B) is True: In 1-D block distribution, Process \(P_0\) owns rows \(0 \dots (n/p)-1\). Once those initial rows are eliminated in the forward reduction sweep, \(P_0\) has zero remaining rows and sits completely idle for the rest of the algorithm! In 1-D cyclic distribution, row \(i\) is assigned to process \(P_{i \bmod p}\). Because rows are interleaved round-robin, every processor owns rows across the top, middle, and bottom of the matrix, maintaining uniform processor utilization until the very final iterations.
• Why others are false: Cyclic distribution does not eliminate communication; it does not change matrix structure or convert Gaussian elimination into a tree.
3
When mapping a sparse matrix-vector multiplication \(y = A x\) using \(k\)-way graph partitioning (e.g., METIS), what do cut edges represent physically?
  • (A) The count of hardware cores that stalled or overheated.
  • (B) Data elements of vector \(x\) that must be communicated across the network between different physical processes.
  • (C) Unreachable memory leaks within the C runtime environment.
  • (D) Floating-point instructions pruned due to zero entries.
Answer: (B) Inter-Process Network Message Transfers
• Why (B) is True: In sparse matrix-vector multiplication, an edge \((i, j)\) in the adjacency graph signifies that computing row \(i\) requires vector component \(x_j\). When vertex \(i\) and vertex \(j\) reside in different partitions assigned to different processes, an edge cut occurs, requiring an explicit network message transfer. Minimizing edge cuts while balancing partition vertex weights directly minimizes total inter-process communication volume while balancing non-zero floating-point operations.
• Why others are false: Edge cuts are graph-theoretic metrics representing communication dependencies, not hardware faults or memory leaks.

In the hierarchical mapping of parallel Quicksort, how does the system avoid the single-processor Amdahl's Law serialization trap at the root of the recursion tree?
  • (A) By using serial bubble sort at the root level.
  • (B) By having all \(p\) processors cooperatively partition the initial array using parallel data decomposition before bisecting into independent sub-teams.
  • (C) By executing the root partition on a quantum processor.
  • (D) By skipping the pivot partitioning step entirely.
Answer: (B) Cooperative Upper-Level Data Partitioning
• Why (B) is True: Pure recursive decomposition assigns the entire root array to 1 processor while \(p-1\) processors idle during the sequential partition phase \(\Theta(n)\) (Amdahl's serialization bottleneck). Hierarchical mapping overcomes this trap by using parallel data decomposition at the root: all \(p\) processors cooperate to partition the array around the pivot in parallel time \(O(n/p + \log p)\). Once the two subarrays are formed, the processor pool is bisected into two teams of \(p/2\) processors, repeating recursively until single-processor leaves are reached.
• Why others are false: Bubble sort is \(O(n^2)\) and worsens performance; pivot partitioning cannot be skipped in Quicksort.
