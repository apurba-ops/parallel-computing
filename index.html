Core Competencies

What You Will Learn

Key pillars of the parallel computing curriculum at BITS Pilani.

Parallel Architectures

Multicore CMPs, cache coherence (MSI/MESI), memory consistency models, interconnect topologies, and hardware multithreading (SMT/CMT).

Shared Memory (OpenMP)

POSIX threads, OpenMP compiler directives, tasking, work-sharing loops, synchronizations, critical sections, and lock-free programming.

Distributed Memory (MPI)

Message Passing Interface (MPI), point-to-point non-blocking semantics, collective communications, parallel I/O, and hybrid OpenMP+MPI clusters.

GPU Acceleration (CUDA)

SIMT execution, warp scheduling, shared memory banking, coalesced memory transactions, and high-performance kernel design in CUDA C/C++.

Structure

Course Modules Breakdown

Comprehensive curriculum organized into foundational and advanced units.

1

Architectures & Multicore

  • Single-core Von Neumann limitations & ILP bottlenecks
  • Chip Multi-Processing (CMP) & Simultaneous Multithreading (SMT)
  • Memory wall, cache hierarchies (L1, L2, L3) & interconnection networks
  • Cache coherence (MSI/MESI/MOESI) & memory consistency
2

Shared Memory (OpenMP)

  • POSIX threads (pthreads), race conditions & mutual exclusion
  • OpenMP directives: parallel for, sections, reduction & tasking
  • Synchronization primitives: barriers, critical, atomic, and locks
  • False sharing diagnostics & NUMA memory affinity
3

Distributed Memory (MPI)

  • Message passing paradigm & MPI execution model
  • Point-to-point communication: blocking vs non-blocking
  • Collectives: Bcast, Scatter, Gather, Allreduce, Scan
  • Parallel matrix algorithms (Cannon's, Fox's) & scaling laws
4

Accelerators & CUDA

  • GPU hardware architecture & SIMT execution paradigm
  • CUDA programming: thread blocks, grids, and kernel launch
  • Memory optimization: global, shared, constant & texture caches
  • Asynchronous transfers, CUDA streams, & profiling with Nsight
