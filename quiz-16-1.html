A task dependency graph has a total work W = 120 FLOPs and a critical path length L = 30 FLOPs. What is the average degree of concurrency, and what does it bound?
  • (A) Concurrency = 0.25; bounds memory bandwidth.
  • (B) Concurrency = 4.0; represents the theoretical average speedup potential.
  • (C) Concurrency = 90; bounds network packet congestion.
  • (D) Concurrency = 3600; represents maximum peak FLOPS.
Answer: (B) Concurrency = 4.0; Theoretical Average Speedup
• Why (B) is True: Average degree of concurrency is defined as Total Work / Critical Path Length = W / L = 120 / 30 = 4.0. It represents the average number of active tasks throughout execution. By the Work-Span model, speedup on p processors cannot exceed W/L.
• Why others are false: (A) inverts the ratio; (C) and (D) are irrelevant arithmetic operations.
2
What is the fundamental mathematical distinction between a Task Dependency Graph and a Task Interaction Graph?
  • (A) Dependency graphs must be Directed Acyclic Graphs (DAGs) representing temporal precedence; Interaction graphs are typically undirected/bidirectional representing spatial communication.
  • (B) Dependency graphs represent network hardware; Interaction graphs represent CPU cores.
  • (C) Dependency graphs can have cycles; Interaction graphs cannot.
  • (D) There is no mathematical distinction; they are identical.
Answer: (A) DAG (Temporal) vs. Bidirectional (Spatial)
• Why (A) is True: A dependency graph models execution order constraints and data production, and must be strictly acyclic (DAG). An interaction graph models concurrent communication and data sharing between active tasks, and can contain cycles and undirected edges.
• Why others are false: Neither graph represents hardware topology directly; dependency graphs cannot contain cycles (C).
3
When multiplying an n × n dense matrix with an n-dimensional vector, why can there be no more than n² concurrent tasks?
  • (A) Because cache lines are restricted to n bytes.
  • (B) The total computation contains exactly n² scalar multiplications, which represent the atomic limit of decomposition.
  • (C) OpenMP prohibits thread counts greater than n².
  • (D) The hypercube dimension is bounded by log₂(n).
Answer: (B) Atomic Limit of n² Scalar Multiplications
• Why (B) is True: Dense matrix-vector product yi = Σj Aij bj requires computing n × n = n² products Aij · bj. Once each scalar product is assigned to an individual task, no further decomposition is possible without breaking fundamental arithmetic operations.
• Why others are false: Hardware cache lines and hypercubes do not restrict algorithmic task definition.
4
In sparse matrix-vector multiplication where Task i holds bi and computes yi, what determines the topology of the Task Interaction Graph?
  • (A) The physical arrangement of DRAM memory channels.
  • (B) The non-zero sparsity pattern of matrix A: an edge exists between (i, j) iff Ai,j ≠ 0 or Aj,i ≠ 0.
  • (C) The clock frequency of the processor cores.
  • (D) The Gray code reflected order of task IDs.
Answer: (B) Non-zero Sparsity Structure of Matrix A
• Why (B) is True: Task i computes Σj Aij bj. It requires vector element bj if and only if Aij ≠ 0. Since Task j stores bj, communication between Task i and Task j is strictly dictated by the non-zero structure of A, creating a 1-to-1 graph isomorphism.
• Why others are false: Interaction topology is an algorithmic invariant independent of DRAM channels or Gray codes.
